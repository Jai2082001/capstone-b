# 🏠 Homeless Support Blog – Capstone Project

This was a solo **Next.js** frontend project for my capstone. The idea was to create a simple blog site where people can share useful resources and schemes for homeless support — things like shelters, food banks, and aid programs.

I also integrated **Google Maps** to show where these resources are located in real life.

---

Here's the Demo

https://homecarefront.vercel.app/home

## 🔧 Features

- Add blog posts and resource updates  
- List support services (meals, shelters, etc.)  
- Google Maps to show nearby locations  

---

## 🛠 Tech Stack

- Next.js (React)  
- Google Maps API  
- Basic CSS  

---

## ⚠️ Notes

- It's fully frontend — no database or backend yet  
- The UI is basic but functional
